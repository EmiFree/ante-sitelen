# sitelen-ante
A tool and website for converting between different toki pona writing scripts. Using mappings from [sona.pona.la](https://sona.pona.la/wiki/Writing_systems). I am not currently using iotated vowels or mulltigraphing, but will probably get around to it eventually. 

## Supported Scripts
* Latin
* Greek (Not multigraphed)
* Cyrillic (No iotated vowels)
* Hiragana
* Katakana

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
