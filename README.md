# sitelen-ante
A tool and website for converting between different toki pona writing scripts. Currently latin, greek, and cyrillic are supported, using mappings from [sona.pona.la](https://sona.pona.la/wiki/Writing_systems).


## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
